## Introdução
O <strong>Flex Seat </strong> é um serviço de reserva de estação de trabalho. A ideia inicial é construir uma ferramenta para colaboradores realizarem a reserva da mesa de trabalho, permitindo um controle de acesso e fluxo de funcionários evitando a super lotação e incovenientes.
